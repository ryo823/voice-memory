## 観察

**回復したもの**
- temporal（0→0.85）と composite（0→1.0）。クエリ全体を1語にしていた AND 検索をやめ、「記録」「メモ」などの文脈語が混ざっても内容語（「面談」「結婚式」「入院」等）で当たるようになったため。ただし日付は解釈していないので、当たっても月の違うメモが混ざり MRR は 0.64。
- paraphrase の一部（0→0.53）。語が部分的に重なるもの（「アレルギーの薬」→「花粉症の薬」、「ご近所トラブル」→「近所の犬」）。

**残ったもの**
1. **語彙が重ならない言い換えは0件のまま**（意味検索の領域）。q12「転居」→「引っ越しの検討」、q23「食器を自動で洗う機械」→食洗機、q26「地震や火事への備え」→防災訓練、q22「ぎっくり腰の治療」（正解 m53 は別表現）。
2. **no_match の FPR が 0→0.70**。OR 化で1語でも当たれば返すため。q55「ハワイ旅行の費用」・q57「ゴルフの予約」は10件返る（「旅行」「費用」「予約」で当たる）、q60「英検の結果」は16件。第1週が指摘した「0.000 は緩い検索で悪化する」がそのまま出た。閾値・最低一致語数・bm25 スコア下限の導入が必要。
3. **tag が悪化**（R@10 1.0→0.75）。q20「健康」は Janome が「名詞,形容動詞語幹」とするため内容語に入らず空クエリ→0件。短い名詞でも品詞が対象外だと落ちる（指定の品詞リストどおりの挙動）。q60 の「英検」も「英」「検」に分割され、本来 trigram で拾えた語を逆に壊している。辞書語でない固有名詞・専門語に弱い。
4. **順位の質**: 当たるが先頭でないケースが多い（q30「最初に腰が痛くなったとき」RR=0.09: 「最初」「メモ」などの一般語に引かれ、正解 m53 は返却11件中の11位。q35「十月に記録した結婚式」は29件返り2位）。「最初に」「十月」など時間表現は検索語ではなく絞り込み・並べ替え条件として扱うべき。

**失敗クエリの例**: q12 転居（0件）/ q23 食器を自動で洗う機械（0件）/ q26 地震や火事への備え（0件）/ q20 健康（0件、品詞除外）/ q30（RR=0.09）/ q55 ハワイ旅行の費用（偽陽性10件）/ q60 英検の結果（偽陽性16件）。

## Run2 への示唆

- 方式B は語彙一致の補助線として有効（特に temporal/composite の回復）。意味ベクトル（ruri-v3-30m、`week2-spike.md` 参照）と併用し、語彙が重ならない paraphrase を拾う。
- no_match 対策が必須。FPR を A 並みに戻す条件（最低一致語数／スコア下限／ベクトル類似度との組合せ）を Run2 で評価する。ベクトル単独は no_match の類似度が正解と重なるため閾値だけでは不十分。
- 時間表現は別系統（recorded_at の絞り込み・並べ替え）で扱う。
